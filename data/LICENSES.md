# Inventário de dados e licenças

Este repositório contém somente exemplos didáticos próprios no arquivo `samples/dataset_exemplo.csv`. A declaração CC0-1.0 nesses exemplos deve ser confirmada pela equipe antes da publicação, pois pressupõe que todos os autores concordam em dedicar os exemplos ao domínio público.

| Fonte | URL | Licença | Status | Ação |
|---|---|---|---|---|
| Exemplos próprios em `samples/dataset_exemplo.csv` | Repositório do projeto | Proposta CC0-1.0 | Confirmar autoria/consentimento | Validar antes de publicar |
| `deepset/prompt-injections` | https://huggingface.co/datasets/deepset/prompt-injections | A verificar na data de uso | Não baixado neste scaffold | Registrar licença, versão e atribuição antes de incorporar |
| Lakera Gandalf | https://huggingface.co/datasets | A verificar para dataset exato | Não baixado neste scaffold | Identificar URL exata e licença |
| BIPIA | https://github.com/microsoft/BIPIA | A verificar no repositório oficial | Apenas referência de pesquisa | Conferir licença de código e de dados separadamente |
| InjecAgent | https://github.com/uiuc-kang-lab/InjecAgent | A verificar no repositório oficial | Apenas referência de pesquisa | Conferir licença de código e de dados separadamente |
| Exemplos sintéticos gerados | A registrar | Conforme termos da ferramenta utilizada | Planejado | Registrar gerador, data, prompt/template e revisor humano |

**Regra:** não adicionar dados públicos ao dataset final até verificar a licença dos dados (não apenas a licença do código), atribuição, uso comercial e condições de redistribuição. Não inserir dados reais de clientes da Intelliway.
